# 中文 agent 规则

一套给中文对话场景写的 agent 规则。四节，整段拷进你自己的全局配置（`AGENTS.md` / `CLAUDE.md` / 系统提示词）就能用，不用改。

它针对的是一件事：模型默认写出来的中文，读起来像在说给所有人听，结果谁也没接住。英文侧已经有人在做这种约束（Karpathy 前阵子推 ASD-STE100，简化技术英语），但中文通用任务，尤其是中文写作和给一个人做汇报，那套规则基本不成立。这里是中文这一侧的版本。

## 里面有什么

- `rules.md`：四节规则，拷这一个文件。
- `examples.md`：每条规则的翻车例子和改写前后。看例子比看规则快。
- `LICENSE`：CC BY 4.0。

## 四节

1. 不许 AI 腔。病根是「写给所有人」这件事，附两条自查判据。
2. 先给结论；要读者动手的句子必须能单独读懂。
3. 汇报分两栏：你要做什么 / 我这边在办。
4. agent 什么时候可以自己定，什么时候必须问。

## 怎么来的

全部是一次次翻车翻出来的。每次 agent 交出来的东西读着不对，就把原因写成一条规则，下回它得照着过。所以 `examples.md` 里的例子都真发生过，只把人名和场景去掉了。
